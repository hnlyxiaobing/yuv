## 0. 现状基线（实测核对，开发前必读）

能力点清单（P1 基准，仓库自足文档 + 公开 API 面核对后确立）：

- F1 四种 YUV 输入格式（NV21/NV12/YUV_420_888/I420）→ 四种 RGB 布局（RGB/BGR/RGBA/BGRA）
- F2 显式 `PlaneDescriptor` 的 `row_stride`/`pixel_stride` 采样（忽略 padding，NV21/NV12 色度 `pixel_stride` 强制 2）
- F3 四种显式色彩矩阵（BT.601/709 × 有限/全幅度），round-half-up 取整，clamp 饱和 / 模 256 环绕双模式
- F4 `to_rgb_fast` Q16.16 定点查表 + 2×2 批量内核（与参考路径循环距离 ≤1 LSB）
- F5 `rotate` D0/D90/D180/D270 与 `mirror_x`；`ConvertConfig` 内几何组合（先旋转、后镜像）
- F6 `RgbImage::{channels, bytes}` 访问器与 `timestamp_ns` 透传
- F7 `YuvError` 7 构造 fail-closed 校验（尺寸/平面数/平面长度/stride/缓冲长度）
- F8 6 项基准与 `tools/bench-gate.ps1` 阈值门禁（脚本层，不属五门禁）
- F9 非目标边界：无 I/O/编解码/缩放/色彩增强/SIMD，不感知相机与模型

非目标清单：不取帧、不编码/解码、不缩放、不做色彩增强、不引入 SIMD 快路径或第三方色彩库、不感知相机或推理模型；跨库帧适配由组合根承担。

## 1. 硬约束（每个工作包都必须满足）

1. API 冻结：`pkg.generated.mbti`（含 `cmd/main` 快照）为冻结基线，只允许纯加法；禁止给 6 个 `pub(all)` 值类型加字段；禁止新增错误变体（`YuvError` 7 变体冻结，破坏性需求走 ADR+用户裁决+CHANGELOG+主版本四件例外）；校验失败复用既有变体；语义变更走新函数新类型防火墙（W5 及未来扩展）。
2. 加法三件套：快照随源码同提交且 diff 纯加法 + `docs/CHANGELOG.md` 登记 + CI 快照门禁绿。
3. 依赖不动：零第三方依赖；工具链按 CI 锁定；`FrameConverter` 若要落地，只能以 `pub impl` 纯加法实现，不改 trait 方法集。
4. 许可红线：公开标准系数不产生入库义务；参考包原文未逐文件核验前不进入分发产物，文档只用泛称并标 [需联网核实]；不引入任何第三方色彩库或二进制。
5. 五门禁全绿才可合入；`#skip`/SKIPPED/退出码 78 不得写成通过；基准脚本失败即 FAILED，不计入门禁通过数。
6. 边界不变量：不取帧、不编码/解码、不缩放、不做色彩增强、不引入 SIMD；显式矩阵/stride 参数不得被隐式默认值替代；定点快路径与浮点参考的 ≤1 LSB 契约冻结，容差不放宽。
7. 文档自包含：本文、配套文档、代码注释、帮助文本与脚本不得引用工作区路径或兄弟模块符号（B15/B16 为现存违例，W1 清理）。

## 3. 边界裁决（P3 结论）

**本质职责（一句话）**：把 4:2:0 YUV 帧的字节平面按显式 stride、色彩矩阵与几何参数**忠实转成 RGB 字节值**——只回答「每个像素应该是什么颜色、输入能否安全读取」，永不回答「帧从哪来、给谁用、怎么编码或缩放」。

**边界判据**：是否停留在「纯值输入 → 纯值字节输出 + 可判定错误」且零 I/O、零平台依赖、参数全显式。满足者界内；需要相机、编解码、缩放、增强、SIMD 调度者界外。

| 灰区 | 判据结论 | 裁决 | 落点（W#） |
|---|---|---|---|
| G1 `to_rgb_fast` 定点路径 vs 浮点参考 | 界内实现优化（无 SIMD、无状态） | 冻结 ≤1 LSB 循环距离与几何/装箱一致性；差异只在新函数内演进 | W3 |
| G2 `rotate`/`mirror_x` 独立工具 | 界内：仍是像素值重排；缩放/增强界外 | 冻结四角枚举与索引律；缩放需求走新函数新类型防火墙 | W3、W5 |

### W3 数值/几何 golden 与双目标差分（P1/M）

**目标**：把 48 条断言升级为可回归契约：4 格式 × 4 布局 × 4 矩阵 × 2 装箱模式的数值 golden、非紧凑 stride 采样、旋转/镜像索引律、快慢路径 ≤1 LSB 全边界、wasm/native 逐字节差分（B3/B7–B11）。
**非目标**：不改任何 pub API；不放宽 ≤1 LSB 契约；不引入 SIMD 或第三方色彩库。
**新增 API**：无。
**实现要点**：
- `tests/golden/`（确定性自产帧 builder）覆盖紧凑与非紧凑 stride（含奇偶尺寸与 padding）、NV21/NV12 色度序（VU/UV）、I420/YUV_420_888 三平面、四矩阵四布局与 clamp/wrap 组合。
- 性质：同输入双次输出逐字节相等；`rotate(D90)` 后再 `rotate(D270)`（及四角组合）回到原像素；`mirror_x` 幂等；四通道 alpha 恒 `0xFF`；快慢路径循环距离 ≤1 LSB（9³ 边界 + ≥1000 固定种子变异）；`to_rgb` 与 `to_rgb_fast` 在旋转+镜像组合下输出对齐。
- 截断扫描：每个帧平面全前缀 + 结构边界（最后一行/最后一列），只允许 7 类 `YuvError`，无 panic/挂起。
- 双目标：同一 builder 在 wasm/native 各跑一次，值输出逐字节 diff=0；若浮点边界出现差异，先定位再定容差口径并写入测试文档，不静默放宽。
**验收**：T-W3-1 golden 入库且被测试真实读取；T-W3-2 数值/stride 性质全绿；T-W3-3 截断+变异扫描无 panic；T-W3-4 wasm/native 值输出 diff=0；T-W3-5 旧 48 用例零改动全绿（防火墙）；T-W3-6 7/7 错误簿记门禁化。
